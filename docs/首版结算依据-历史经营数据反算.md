# 首版结算依据：历史经营数据反算

本文由 2025-01 至 2026-09 的历史经营数据反算而来，是规则库的首版结算依据。只收录历史数据里**金额完全吻合**的规律；其余科目的规则，后续导入合同、制度、价目表等依据文本，由 AI 解析提取，管理端确认后发布。

## 一、数据范围与方法

| 项 | 内容 |
| --- | --- |
| 数据来源 | 《单井经营情况导出模板》导入的“历史导入”经济事项 |
| 范围 | 505 口井（长庆 321、大港 98、西北 86），每口井一条单月记录，月份跨 2025-01 至 2026-09 |
| 形象收入 | 497 口井有形象收入（R02），合计约 43.6 亿元 |
| 口径 | 历史数据只有各科目金额，没有工作量（进尺按井累计、没有分月）。因此只能反算“金额 ÷ 收入”“金额 ÷ 进尺”和整井月定额三类规律 |
| 入库标准 | 同一市场内，至少 95% 的井金额与规律完全一致（比例类、单价类），且样本不少于 80 口井 |

示例数据（W001–W004）及其测试规则不参与反算，已随规则库一并清理。
