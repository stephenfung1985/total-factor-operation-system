# 全要素经营管理系统 v3.0 UI 原型

在线画布：https://claude.ai/artifact/1M2ZVe1rKXfhotiz8CqJUV （需分享后他人才能打开）

这里存的是画布的源文件，格式为 Design Component（`.dc.html`），依赖画布运行时，不能直接用浏览器打开。

| 文件 | 内容 |
| --- | --- |
| `project/canvas.json` | 画布索引：两块画板的位置、尺寸和名称 |
| `project/Main.dc.html` | 可交互原型：顶部系统名称与角色切换、浅色/深色模式；经营总览 → 单井 → 成本构成（固定成本 + 变动成本分级，未发生项目列全）→ 经济事项 → 溯源面板；单井经营情况导出预览；成本日报、规则确认、单井基础信息、主数据维护、角色与权限 |
| `project/Architecture.dc.html` | 信息架构与权限层级：四层导航、下钻链、角色工作台、两级权限 |

成本项目树数据由 `tools/build_cost_tree.py` 从《单井经营情况导出模板》和设计文档附录 A 生成，嵌在 `Main.dc.html` 的 `treeData()` 中。界面中 W001 的金额取自导出模板示例井，W002–W004 按比例缩放，均为示例数据。

口径：总成本 = 固定成本 + 变动成本（变动成本含安全计提、科研计提、税金）；毛益额 = 形象收入 − 变动成本；净利润 = 形象收入 − 总成本。
